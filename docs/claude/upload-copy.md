# 유튜브·인스타 업로드 문안 양식 (CLAUDE.md 2.0.2 에서 옮김 — 2026-11-23, 내용 그대로)

> 최종 갱신: 2026-11-23
> 유튜브 「농민일기」·인스타 문안을 쓸 때 읽는다. 서브에이전트 `upload-copy`(.claude/agents)가 같은 양식을 갖고 있다. 둘이 어긋나면 이 파일이 기준.

### 2.0.2 업로드 문안(제목·쇼츠·태그)은 파일 말고 **채팅으로** (2026-08-31 지시)
유튜브·인스타그램에 올릴 **제목 / 쇼츠 문안 / 태그·해시태그 / 설명문**은 md 파일로 만들지 말고
**이 세션 채팅창에 바로 붙여서** 보낸다. 대표님이 그 자리에서 복사해 쓰신다.
- 파일로 만들면 열어서 찾아 복사하는 단계가 하나 더 생긴다. 그게 불편하다는 지시다.
- 태그는 **줄이지 말고 전부** 적는다. "… (20개)" 같은 생략 금지 — 복사할 수 없다.
- 편집 주의사항·촬영 기록처럼 **나중에 다시 볼 것**만 파일로 남긴다
  (기존 `농민일기/youtube/episodes/` 는 그대로 두되, 문안 자체는 채팅에도 같이 보낸다).

**유튜브 설명문 양식** (2026-09-01 대표님이 1·2화를 직접 다듬어 확정한 형태):
```
훅 2~3줄            ← 궁금증을 쌓고 시작. 실제 대사가 있으면 "인용구", 없으면 사실 나열

장소와 사람 소개 2줄

반전·의외의 한 줄 + ".. ㅎㅎ"
짧은 마무리 한 줄     ← 여운. 나열·요약 금지

📍 행사 정보 (있을 때만)

#해시태그 5개 안팎    ← 본문 안에 둔다

━━━━━━━━━━━━━━━━━━━━
0:00 챕터
...
━━━━━━━━━━━━━━━━━━━━

「농민일기」는 땅을 지키는 사람들의 하루를 기록합니다.
한 편에 한 농가, 그 사람이 지어온 시간을 그대로 담습니다.
```
지켜야 할 것 — **전부 대표님이 직접 고쳐 알려준 것들이다:**
- **챕터는 6~7개.** 16개로 쪼개지 말 것. 1분 미만 간격(예: 10:54 / 11:15)은 합치거나 하나를 버린다
- **챕터 제목은 설명이 아니라 훅** — "빵터지는 말통사건" "청양군 토막살인미수(?)" "밥먹으러 가자"
- **전언체 금지** — "찾아왔다고 하고요" ❌ → "찾아왔습니다" ⭕. 짧게 단정한다
- **마무리는 한 줄 여운.** "30년의 땀이 전하는 진솔한 이야기입니다" 처럼.
  내용을 다시 나열하며 끝내지 말 것 (대표님이 매번 지운다)
- **`출연 :` / `촬영 :` 줄은 넣지 않는다** — 두 편 다 제거하셨다
- **설명문에 농민.com 링크를 넣지 않는다** — 넣을지 여쭸을 때 안 넣는 쪽으로 정하셨다
- 마지막 두 줄(채널 소개)은 **고정**. 토씨 바꾸지 말 것

**태그 어휘 선호**: 사람을 가리키는 말은 관계·순번보다 **장인(匠人) 계열**을 쓴다.
- ✅ `전통주장인` `전통술장인` · ❌ `3대째`
- 채널·서비스 축(`농민일기` `농민닷컴` `산지직송`)은 편이 바뀌어도 계속 넣는다.
