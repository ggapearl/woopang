# 보물찾기 — 서버 API · 규칙 · 앱 화면 계획

> 담당: 보물찾기 세션(Windows). 다른 세션은 메세지 시트 구조·`Runtime/Hunt/`·`Redesign0926ApplyHunt*`·`hunt_` 알림·설정 '보물찾기' 묶음·`/api/hunts` 를 건드리지 않는다.
> 서버 코드는 `server/hunts/hunts_server.py`(git 미추적 — 로컬 전용, 메인 서버 8080 에 블루프린트로 붙음). 2026-10-05 운영 반영 · 실제 DB 시험 143개 통과.

## 1. 게임 한 판

- **숨기기**: 주최자가 그 자리에 가서 연다 — 요청 순간 기기 GPS 가 보물 좌표(정확도 30m 이내 · 모의 위치·순간이동 거절). 관리자만 좌표 지정·반경/시간 무제한(공식 이벤트).
- 옵션: 제목·힌트 · 성공 방식(선착순 터치 / 코드 입력 — 10분에 5번 틀리면 잠김) · 당첨 인원(1~100 또는 제한 없음) · **참가 인원 상한**(1~100 — 앱 칩 10·20·30·50·100, 기본 30 · 당첨 수 이상 · 관리자는 비우면 제한 없음 · 2026-10-12 대표님) · 반경 1~100km · 보이는 거리 10~200m(앱 오브젝트는 기본 프리팹과 같은 확대·축소, 200m 전체 규칙 안에서 더 가까이만) · 좌표 공개(정확 / 대략 100·300·1000m 원 — 중심을 실제 자리에서 비켜 둠 / 비공개 — 굵은 거리 글만) · 대상(모두 / 맞팔만 / 참가 코드) · 상품 · 시작(바로 / N분·시간·일 뒤, 30일 안) · 진행 15분~7일.
- 일반 주최자 제한: 하루 3개 · 동시에 2개 · 정지된 주최자는 못 엶.
- **참가**: 범위 안에서(참가 코드 게임은 어디서든) · 차단한 사이·친구 아님은 안 보이고 못 함 · 인원이 차면 `full`(게임 행을 잡고 세서 동시에 눌러도 넘치지 않음 · 누가 나가면 빈자리).
- **근접** `/near` (8초에 한 번): 단계 1km·300m·100m·30m · 보이는 거리 안이면 보물 좌표를 줌(대략·비공개 게임도 이때만).
- **판정** `/claim`: 서버만 믿는다 — 거리(보이는 거리 기준 15~30m) · 정확도 50m · 모의 위치 · 순간이동 · 한 기기 한 번 · 동시 터치는 행 잠금으로 한 명만.
- **찾은 뒤**: 참가자·주최자에게 '○○님이 보물을 찾았어요' · 찾은 사람 메시지 → 참가자·주최자(주최자에겐 1:1 메시지로도).
- **시간 늘리기**: 아직 못 찾은 참가자에게 '보물찾기 시간이 늘었어요 — HH:MM까지 (30분 더)'(`hunt_extend` · 늘린 사람 빼고 · 관리자가 늘리면 주최자도) — 2026-10-12 대표님.
- **알림 끊기(참여 거부)**: 게임 하나는 '나가기'(참가 줄이 지워져 그 게임 알림이 모두 끊김) · 전부는 설정 '보물찾기 참여' 끄기(목록·새 게임 알림에 더해 참가해 둔 게임 알림도 끊김 · 주최자는 자기 게임 소식을 늘 받음).
- **시간 넘기기**(30초마다): 예약 → 10분 전 알림 → 진행 → 끝. 밤 22~08시엔 '새 게임' 알림을 미뤘다가 아침에.

## 2. 주최자에 관한 건 전부 그 사람 프로필에서 (2026-10-05 대표님)

시안: `C:\woopang-app\mockups\우팡_보물찾기_프로필_1005.html`(.png)

- 프로필 카드 숫자 줄에 **'주최'** 칸(주최한 적 있는 사람만) — 숫자 아래 별(3명 미만이면 '평가 모으는 중').
- 누르면 같은 카드 안에서 펼침: **주최 기록**(주최수·최근 30일·평균 참가·마지막·첫 주최) · 지금 열린 게임 · **참여자 평가**(점수·평가 수) · **리뷰 남기기**(자격 있는 끝난 게임마다 별 5개 + 한 줄 80자) · **참여자 리뷰**(쓴 사람 안 보임) · **주최자 신고 / 차단**.
- 내 프로필: 같은 칸 + 리뷰마다 '신고'. 신고가 쌓여 정지되면 본인에게만 안내.
- 게임이 끝나면 자격 있는 참가자에게 '주최자 프로필에서 별점을 남겨 주세요' 알림(데이터 `review=1`, `host_id`) → 누르면 주최자 프로필.

## 2-1. 처음 주최할 때 수칙 안내 · 신고되면 메시지 (2026-10-05 대표님)

시안: `C:\woopang-app\mockups\우팡_보물찾기_주최안내_1005.html`(.png)

- 처음 '보물 숨기기'를 누르면 **주최 수칙 시트**(8가지 · 서버가 글을 줌 `/api/hunts/rules?lang=ko|en`) → '위 내용을 확인했고 지킬게요' 체크 → `/rules/accept {version}` → 숨기기 4단계.
  앱은 설정·목록 응답의 `host_rules.accepted` 로 미리 안다. 수칙을 바꾸면 서버 `HOST_RULES_VERSION` 을 올린다 → 모두 다시 동의. 동의 없이 숨기면 서버가 `need_rules` 로 막는다.
- 주최자가 신고되면 메세지 목록 **'WOOPANG' 대화**(시스템 계정 회원번호 3 · 서버 저장 + 1:1 메시지 푸시)로:
  `[보물찾기 신고 안내]` 신고 사실·사유·조치·누적(1/3, 2/3) → 3명이면 `[보물찾기 주최 정지]` → 관리자가 풀면 `[보물찾기 주최 정지 해제]`.
  신고한 사람·신고 글 원문은 보내지 않는다(사유 종류만). 관리자가 직접 걸거나 풀 때도 상태가 바뀔 때만 보낸다.

## 3. 평가·신고 규칙 (대표님 승인 ①~⑨)

1. 실제로 나선 사람만 평가 — 찾았거나 게임 중 1km 안까지 간 기록(서버 GPS · `/near`·`/claim`)
2. 끝난 뒤 7일 안 · 한 사람 한 표(기간 안엔 고침)
3. 한 기기 한 표
4. 같은 사람이 같은 주최자에게 준 별점은 평균 내 한 표
5. 3명부터 별 표시 · 보이는 점수 = (3명분 3.5점 + 실제) 평균
6. 주최수는 참가자가 있던 끝난 게임만
7. 누가 몇 점 줬는지 주최자에게 안 보임 — 관리자만 보고 숨김
8. 가입 3일 미만 계정의 별점·리뷰는 3일 뒤부터 반영
9. 5개 이상 매겼는데 80% 이상이 1점인 사람은 반 표

신고: 참가자 → 주최자(그 사람 게임 참가자만 · 사유 5가지) · 주최자 → 자기 게임 리뷰. 기존 관리자 신고함(`reports` · `/admin/reports`)에 함께 쌓이고 효딩쓰 앱으로 알림. **30일 안에 서로 다른 참가자 3명**이 신고하면 관리자가 풀 때까지 주최 정지. 차단은 기존 `/api/block`·`/api/unblock` — 차단한 사이엔 목록·참가·알림 모두 빠짐.

## 4. API (모두 `Authorization: Bearer <로그인 토큰>`)

| | 주소 | 보내는 것 → 받는 것 |
|---|---|---|
| 설정 | `GET/POST /api/hunts/prefs` | `{enabled, notify_new, notify_near}` |
| 숨기기 | `POST /api/hunts` | title, hint, mode(touch/code), code, question, winners / winners_all, max_players(→ 400 `players` {max 또는 min}), radius_km, visible_m, coord_mode, approx_m, audience, prize, after_found, object_kind/url, start_in_min, duration_min, lat, lon, acc, mock → `{hunt, join_code}` |
| 목록 | `GET /api/hunts/nearby?lat=&lon=` | `{prefs, admin, hunts, hosted, joined}` |
| 상세 | `GET /api/hunts/<id>?lat=&lon=` | `{hunt}` — participants·max_players·full · feed·finders·me(joined, rank, tries_left, can_rate, my_rating)·rate_until·host(주최 통계) |
| 참가/나가기/포기 | `POST /api/hunts/<id>/join` {lat,lon 또는 code} · `/leave` · `/giveup` | 다 차면 403 `full` {max_players} |
| 코드로 참가 | `POST /api/hunts/join_code` {code} | 참가 코드 게임은 목록에 안 보인다 — 코드만으로 (어디서든) |
| 근접 | `POST /api/hunts/<id>/near` {lat,lon,acc} | `{band, visible, claim_m, object?}` · 8초 안에 또 → 429 |
| 판정 | `POST /api/hunts/<id>/claim` {lat,lon,acc,code?,mock?,device_id} | `result`: found · too_far · wrong_code · need_code · locked · taken · ended · not_started · not_joined · host · weak_gps · mock_location · teleport · device_used |
| 메시지 | `POST /api/hunts/<id>/message` {text} | 찾은 사람·주최자만 |
| 주최자 | `POST /api/hunts/<id>/end` · `/extend` {minutes} · `/reveal` | |
| 별점 | `POST /api/hunts/<id>/rate` {stars, review?, device_id} | 403 사유: host · not_ended · closed · not_joined · not_played · device_used |
| 프로필 | `GET /api/hunts/profile/<아이디>` | `{host:{hosted, hosted_30d, first_at, last_at, avg_participants, rating, raters, open, recent}, reviews, me:{is_me, blocked, blocked_me, reported, can_report, can_review[]}, suspended(본인·관리자만), report_reasons, review_report_reasons}` |
| 신고 | `POST /api/hunts/report` | `{target:"host", host_id, hunt_id?, reason, detail?}` 또는 `{target:"review", rid, reason, detail?}` |
| 주최 수칙 | `GET /api/hunts/rules?lang=` · `POST /api/hunts/rules/accept` {version} | `{version, accepted, title, agree, items[{icon,title,body}]}` · 판이 다르면 409 · 설정·목록 응답에 `host_rules` |
| 관리자 | `GET /api/hunts/ratings?host_id=` · `POST /api/hunts/ratings/hide` {rid, hidden} · `POST /api/hunts/host/<id>/suspend` {on} | 관리자: `.env HUNT_ADMIN_USER_IDS` 또는 /admin 로그인 |

푸시 `msg_type`: `hunt_new` · `hunt_start` · `hunt_found` · `hunt_message` · `hunt_extend` · `hunt_end`(+`review=1`, `host_id`) — 모두 `hunt_id` 포함.
