# 효딩쓰 안드로이드 — 바뀐 것

APK 를 새로 줄 때마다 맨 위에 한 덩어리씩 적는다. 화면(web/)만 바뀐 것은 「화면」 줄에 날짜로.

- 화면 2026-10-01 — 같은 화면이 `https://woopang.com/hyodingsseu/` 에서도 열린다(nginx → AI Office 의 /AI/desk-app/). 아이폰 2.0 「포장지」 앱이 여는 곳.
  manifest 시작 주소를 상대(`./`)로 — 어느 주소로 열어도 맞게. 이 앱(APK)은 지금처럼 `/AI/desk-app/` 을 연다(같은 파일).
- 화면 2026-09-30 — 말풍선마다 받은 시각을 작게(텔레그램처럼, PC 가 붙이는 `ts`). 「읽기」에는 안 들어감. 서버에서 바로 바뀌어 APK 다시 안 깔아도 된다.

## 1.0.1 (10001) — 2026-09-28 첫 버전

아이폰 앱 1.0.1 과 같은 기능·버튼·로직:
- PC 효딩쓰와 같은 대화 (지금까지 대화 받아오기 + 긴 폴링 · 글자 단위로 흘러나옴)
- 글로 시키기 · 말로 시키기(누르고 말하고 다시 누르기 → PC 가 받아적음, 60초면 저절로 보냄)
- 허락 카드(허락 / 계속 허락 / 거절) · 선택 카드(하나 고르면 바로, 여럿이면 「이대로 답하기」)
- ☰ 대화 상대: 효딩쓰 · AI Office 직원 15명(일하는 중이면 분홍 고리) · 설정 · 새 대화
- 직원과 따로 대화 (지시 → 답 올 때까지 3초마다 확인, 최대 4분)
- 답마다 「읽기」 — 폰 목소리 또는 PC 소희 목소리(/tts), 읽는 중엔 「멈춤」
- 답을 소리로(듣지 않기 · 말로 물었을 때만 · 항상) · 말 빠르기 0.8~1.6배(PC 소희 목소리에도 적용)
- 연결 코드(6자리)로 짝 짓기 · 연결 끊기(PC 쪽 열쇠도 지움) · 라이트/다크 · 빨간 고양이 아이콘

안드로이드에서 더한 것:
- 화면을 woopang.com/AI/desk-app/ 에서 받아 온다 — 화면을 고쳐도 APK 를 다시 깔 필요 없음
- 뒤로 가기: 메뉴·서랍·확인 창 → 직원 대화·설정 → 앱 내리기(끄지 않음)
- 화면 색 고르기(폰 설정대로 / 라이트 / 다크) — 상태바·내비게이션 막대 색도 같이
- 위를 읽는 중엔 새 글이 와도 끌어내리지 않고 「↓」 단추 (내 말·허락 카드·선택 카드는 바로 내려감)
- 답 속 링크는 앱 밖(브라우저)에서 연다 · 코드 블록은 고정폭 상자
- 폰에 한국어 목소리가 없으면 PC 소희 목소리로, PC 목소리가 안 되면 폰 목소리로
- 서버에 닿지 않으면 앱 안 안내 화면 → 20초마다 다시 시도
- 연결 토큰은 백업·새 폰 옮기기에서 빠진다(아이폰 Keychain ThisDeviceOnly 와 같은 뜻)
